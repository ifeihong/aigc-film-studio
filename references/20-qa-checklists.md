# 20 QA Checklists — 生成前审查 + 生成后画面质检

> 定位：作为统一质检关。
> 用法：**每镜提示词发出前过 Part A/B；每段素材入库后过 Part C；发现问题按 Part D 路由修复。**

---

## Part A — 视频提示词·生成前审查（逐镜必过）

合并自 CINEDANCE 无声自我 QA + ACTING 发送前清单。任一项为「否」→ 先修提示词再发。

### A1. 结构与空间（CINEDANCE）
- [ ] SCENE CONTEXT 开头有「EXACT N CHARACTERS — NO DUPLICATES」，人数与参考图一致
- [ ] 所有活跃 @tag 真的用于本镜；过期 @tag 已移除
- [ ] 每个参考都命名了角色（for character/location reference）；地点参考带「不继承构图/角度/色调」禁令
- [ ] 本场景 GEO SPATIAL LAYOUT 已逐字粘贴；摄影机一侧与 180° 轴线写死
- [ ] 第一帧正确：首秒为 wide、无台词无动作、人物立即可见
- [ ] 每个角色位置清晰；视线清晰；身体朝向清晰；地标邻近有物理锚定
- [ ] 切镜后已重述「谁站哪、看向哪」（模型不记得上一镜）

### A2. 镜头·光学·物理（CINEDANCE）
- [ ] 镜头性格按内容类型选定（决策树）；镜头语言基于视觉结果；有防漂移条款
- [ ] 光照单源逻辑、方向明确、防变平；无「两个太阳」
- [ ] 道具在正确的手；动作物理可行；时间块一致（时长=拍数覆盖）
- [ ] 每拍 ≤3 句；复杂动作放在开头「已发生」，不塞时序中段

### A3. 表演与声音（ACTING）
- [ ] 每个镜中角色有目标（瞄准搭档的动词）；障碍与赌注真实
- [ ] 2–4 次节拍变化，每次在行为上可见（停顿/姿态/节奏/视线）
- [ ] 反应始于搭档台词结束前；有评估时刻
- [ ] 每个角色有活计；「打断活计」用作重音
- [ ] 眼生命明确写出：扫视、眨眼质量、眼神光（catch-light）、眼领思想
- [ ] 写行为与肌肉，不写情绪词（sad/angry/shocked 不出现）
- [ ] 群像反应错开（强者静、弱者躁），不同步同刻
- [ ] 台词只在 AUDIO 段、只有引号内那句；无台词角色完全静默；自创"嗯/笑"被硬封
- [ ] 说话的角色的 Voice 描述逐字粘贴；罕见名字带音标
- [ ] 表演量表自评 ≥4；≤2 的段落重写

### A4. 收尾（CINEDANCE）
- [ ] Style Prefix 逐字粘贴；技术标签齐全（画幅/时长/SFX only/NO CGI/Cinematic）
- [ ] POSITIVE CONSTRAINTS 写成「画面里有什么」；计数与禁令明确（人数/道具数/尺度）
- [ ] 防文字乱码：加 `No legible generated text — any writing (signs, letters, books, screens) appears as suggested texture only, never readable words.`
- [ ] 无年龄词；敏感词已换安全表述（dark→low key 等）；最终提示词为英文
- [ ] 未写入画幅/分辨率等 UI 参数；无场景编号/上下文泄漏

## Part B — 图像提示词·生成前审查（LIRA 发送前清单）

- [ ] 路由选对模型：生成→Soul（表可用 AI Cast）；道具→NBP / GPT Image 2；编辑→先 NBP
- [ ] 画幅与分辨率在 UI 设，不出现在提示词文本
- [ ] 自然散文，不堆关键词；CAPS 块（CHANGE/PRESERVE）仅用于编辑
- [ ] 正向 > 负向；编辑里每次移除都带填补（fill）
- [ ] 技术光照（key light / ratio / falloff）+ 具体材质（材质+表面处理），不含糊情绪词
- [ ] 60/30/10 配色来自指令/场景/参考，不发明
- [ ] 角色：Soul ID + 散文锚点
- [ ] 三分法构图（角色表除外）
- [ ] 无品牌 / IP / 真实人物名
- [ ] 不肿：≤1500–2000 字符，砍填充

## Part C — 生成后画面质检（slop 图鉴·文字重建版）

AI 素材的缺陷在小屏看不见、大屏全是。**清理在 picture lock 后单独做一遍，脸与手优先。**

| # | 缺陷 | 识别 | 修复 |
|---|---|---|---|
| 1 | 多余手指 / 肢体增生 | 手部特写、持物镜 | 小范围→后期逐帧修；大面积→改一行重生成 |
| 2 | 「沸腾」纹理（表面爬动） | 墙/皮肤/布料在镜间蠕动 | 后期修或重生成；防漂移条款没写好就补 |
| 3 | 假文字 / 招牌乱码 | 背景招牌、屏幕、纹身 | GPT Image 2 局部手术 / 后期覆盖；前期就该禁文字 |
| 4 | 死脸（瞳孔无眼神光） | 特写眼睛像玻璃珠 | 资产表阶段重生成脸（必带 catch-light）；提示词加 wet living eyes with catch-lights |
| 5 | 换脸 / 换衣 / 身份漂移 | 同角色跨镜不像 | descriptor 不完整或参考角色未命名；角色表正面图未去头 |
| 6 | 人物瞬移 / 跳轴 | 切镜后位置互换、视线反打 | 缺 GEO / 缺首秒 wide / 切后未重述位置 |
| 7 | 塑料皮 / 对称脸 | 脸过滑、左右对称 | 图像被整张二次过模型——违反点修改铁律，回原始资产重做点修改 |
| 8 | 巨人缩水 | 巨人越画越像大人 | 缺 SCALE LAW：尺寸对比 + 人形参照物 |
| 9 | 群演数量失控 | 一镜 3 人一镜 100 人 | 中景直接写 "20+"；主角群演单独资产 |
| 10 | 多出人物 / 克隆家具 | 背景冒出复制人/双沙发 | EXACT N + POSITIVE CONSTRAINTS 明确计数 |
| 11 | 自带配乐 | 生成视频带音乐 | 提示词缺 `SFX only. No music.`；音乐只能后期加 |
| 12 | 模型自创台词 / 尬笑 | 角色说了没写的词 | 缺硬封锁「everyone speaks ONLY the line in quotes」 |
| 13 | 表演平 / 假 | 全程一色、等 cue、死眼 | 对照 `11-acting-performance.md` 坏表演图鉴 15 条，量表 ≤2 重写 |
| 14 | 节奏拖沓 | 整镜偏慢 | 剪辑比感觉更狠地切；每镜裁头尾各半秒（边缘漂移） |

## Part D — 修复路由表

| 问题出在哪 | 修在哪 |
|---|---|
| 提示词能防的（A/B 清单项失败） | 改提示词对应一行 → 重生成（surgical，一次一行） |
| 10–15 次迭代仍不成 | 简化镜头：拆两镜 / 删动作 / 换角度——**改镜头不改文字** |
| 单帧小缺陷（手指/纹理/乱码） | 后期：遮罩点修 / GPT Image 2 局部手术，保原皮肤纹理 |
| 整镜不可用 | 用存档的最终提示词改一行重生成 |
| 资产本身崩（脸不可信/无眼神光） | 回阶段 3 重生成资产表——**别在视频阶段抢救坏资产** |
| 跨镜色调不一 | 调色阶段统一到同一场景 look（资产期已烘焙基调，调色师只做精修） |
| 声音漂移 / 不可用 | 先清理生成音（降噪/匀音色/入空间）；实在无可用才棚录 |
